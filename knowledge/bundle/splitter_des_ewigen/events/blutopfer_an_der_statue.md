# Blutopfer an der Statue

Ein Ritual, das von [Esterossa](../characters/esterossa.md) durchgeführt wurde, um das mächtige Feuerwesen [Lenra](../npcs/lenra.md) zu beschwören.

## Ablauf

Esterossa opferte sein eigenes Blut an einer Statue, die eine böse Gottheit darstellt. Durch dieses Blutopfer gelang es ihm, das Feuerwesen Lenra herbeizurufen.

## Beteiligte

- **[Esterossa](../characters/esterossa.md):** Führte das Opfer durch
- **[Lenra](../npcs/lenra.md):** Das beschworene Feuerwesen
