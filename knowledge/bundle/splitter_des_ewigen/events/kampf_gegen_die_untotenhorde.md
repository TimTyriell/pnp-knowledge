# Kampf gegen die Untotenhorde

Ein groß angelegter, koordinierter Angriff einer Horde Untoter auf die Gruppe. Der Kampf wurde durch einen taktischen Überraschungsangriff der Gruppe entschieden.

## Verlauf

Die Gruppe eröffnete den Kampf, indem sie ein Portal für einen Überraschungsangriff nutzte. [Rotuna](../characters/rotuna.md) entfesselte daraufhin eine mächtige Eisattacke, die den Großteil der gegnerischen Horde auf einen Schlag vernichtete. Die verbliebenen Untoten wurden durch diese Demonstration der Stärke in die Flucht geschlagen.
